# Garki Transit

**Navigate Abuja corridors with clarity.**

Garki Transit is an Abuja urban commuter directory providing a structured reference for key pickup zones, typical travel windows, and corridor links across Garki, Wuse, Asokoro, and the Airport Road axis.

## Key Features
- **Instant Stop & District Search:** Look up stops, districts, or landmarks (such as Garki II, Wuse Zone 4, and Lugbe) to narrow down matching routes immediately.
- **4 Major Axes Overview:** Filter corridors across Central, Garki, Wuse, Asokoro, and Lugbe.
- **Peak Window Reference:** Clear visibility into typical rush-hour windows for Morning (07:00 – 09:30 WAT) and Evening (16:30 – 19:30 WAT) commutes.
